# Hostel Entry and Exit Management Mobile Application

An Android application developed using Kotlin to digitally manage hostel students' entry and exit timings.

## Problem Statement
Manual entry registers in hostels are time-consuming, error-prone, and difficult to monitor. This project aims to provide a simple digital solution to track student movement effectively.

## Features
- Student entry and exit logging
- Timestamp-based in/out records
- Admin view for monitoring activity
- User-friendly interface

## Tech Stack
- Kotlin
- Android Studio
- SQL
